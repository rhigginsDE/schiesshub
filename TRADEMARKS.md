# Name und Logo

Der Quellcode von Schiesshub steht unter der [AGPL-3.0](LICENSE). Der Disziplin-Katalog unter `catalog/` steht unter [CC0 1.0](catalog/LICENSE).

**Nicht** unter diesen Lizenzen stehen:

- der Name „Schiesshub“ und die Domain-Schreibweise `schiesshub.app`
- das Logo, das Emblem und die App-Icons unter `public/icons/` sowie `public/logo.png`

## Was erlaubt ist

- Den Namen nennen, um auf das Projekt zu verweisen („basiert auf Schiesshub“, „kompatibel mit Schiesshub“).
- Die unveränderte Software unter ihrem Namen im eigenen Verein betreiben.

## Was nicht erlaubt ist

- Eine veränderte Fassung oder einen Fork unter dem Namen oder mit dem Logo Schiesshub anbieten.
- Name oder Logo so verwenden, dass der Eindruck entsteht, ein Angebot stamme von den Projektinhabern oder werde von ihnen unterstützt.

Wer einen Fork veröffentlicht, ersetzt bitte Name, Logo und Icons durch eigene.

Fragen dazu bitte als Issue im Repository stellen.
