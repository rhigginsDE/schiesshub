# Schiesshub

Open-Source-Software zur Erfassung und Auswertung von Turnieren im Schießsport.

> 🚧 Projekt in früher Entwicklung.

## Features (geplant)

- Turniere anlegen und verwalten
- Schützen und Mannschaften erfassen
- Ergebnisse eintragen und Ranglisten erzeugen
