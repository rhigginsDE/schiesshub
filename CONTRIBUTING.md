# Mitwirken an Schiesshub

Danke für dein Interesse!

1. Issue eröffnen oder ein bestehendes kommentieren, bevor du größere Änderungen startest.
2. Repo forken und einen Feature-Branch anlegen (`feature/kurze-beschreibung`).
3. Pull Request mit kurzer Beschreibung der Änderung öffnen.

Bitte keine Secrets, Zugangsdaten oder personenbezogenen Daten committen.
