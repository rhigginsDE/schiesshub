# Mitwirken an Schiesshub

Danke für dein Interesse!

## Disziplin-Katalog

Der einfachste Beitrag: eine Disziplin korrigieren oder ergänzen. Das geht ohne Programmierkenntnisse direkt auf GitHub. Format und Regeln stehen in [catalog/README.md](catalog/README.md). Bitte nenne im Pull Request die Quelle (Regelwerk, Fassung, Abschnitt) und kopiere keine Regeltexte.

Katalogdaten stehen unter CC0. Mit deinem Beitrag stellst du ihn ebenfalls unter CC0.

## Code

1. Eröffne ein Issue oder kommentiere ein bestehendes, bevor du größere Änderungen beginnst. Für geplante Module siehe [docs/ROADMAP.md](docs/ROADMAP.md).
2. Forke das Repo und lege einen Branch an (`feature/kurze-beschreibung`).
3. Öffne einen Pull Request mit einer kurzen Beschreibung.

Code-Beiträge von außen können wir erst annehmen, wenn die Vereinbarung zur Rechteeinräumung (CLA) vorliegt. Sie ist in Arbeit. Bis dahin sind Issues, Fehlerberichte und Katalog-Beiträge der beste Weg.

## Grundregeln

- Keine Zugangsdaten und keine echten Personendaten committen, auch nicht in Tests oder Screenshots.
- Nichts fest verdrahten, was ein Verein anders regeln könnte. Solche Dinge sind Einstellungen oder Katalogdaten.
- Oberflächentexte gehören in die Sprachdateien.
- Die Wertung rechnet nur das Backend.
